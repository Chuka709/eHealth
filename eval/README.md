# Eval — шинжилгээний хариуг хэр зөв уншиж байгааг хэмжих

`just eval` нь хариу бүрийг манай уншигчаар уншуулж, таны цаасан хариунаас гараар бичсэн «зөв хариу»-тай мөр мөрөөр нь тулгадаг. Phase 4-ийн DoD:

- тоон утга ≥ 98%;
- лавлах хязгаар ≥ 95%;
- тест таних ≥ 95%;
- нэг хуудас ≤ 30 сек (p95).

## Хавтсууд

| Хавтас | Юу байх | Git |
|---|---|---|
| `eval/cases/` | Зохиомол кейс (`make_synthetic.py` үүсгэнэ) | Репод орно |
| `eval/local/` | **Бодит хариу** (PDF + таны хариу) | **Хэзээ ч орохгүй** (git-ignored, PHI) |
| `eval/report.md` | Сүүлийн тайлан (зөвхөн кейсийн id, тоо) | Орохгүй |

## Бодит кейс нэмэх (нэг хариу = нэг хавтас)

1. Хавтас үүсгэнэ: `eval/local/kidney-1/`, `eval/local/liver-1/` гэх мэт.
   - Нэр нь зөвхөн жижиг латин үсэг, тоо, `-`-ээс бүрдэнэ.
   - Хүний нэр бүү оруул: тайланд орох тул `just eval` ийм нэртэй хавтсыг хүлээж авахгүй.
2. Тэр хавтсанд хариуны PDF-ийг `input.pdf` нэрээр хуулна.
3. `eval/answers_template.csv`-г `answers.csv` нэрээр хуулаад Excel-ээр нээнэ.
   - Жишээ мөрүүдийг устгана.
   - **Цаасан хариугаа харж**, мөр бүрийг гараар бичнэ.
   - Апп-ын уншсаныг хуулж бүү бичээрэй: тэгвэл хэмжилт утгаа алдана.
   - Хадгалахдаа «CSV UTF-8» сонгоно.
4. (Сонголттой) Шинжилгээний төрлийг тэмдэглэхийн тулд `case.json` нэмнэ:
   ```json
   {"tags": ["kidney", "mn"]}
   ```
   - Tag-ийн утгууд: `kidney`/`liver`, улс `mn`/`kr`/`in`/`cn`/`tr`.
   - Монголын УНТЭ биш, апп-ын таньдаггүй хэлбэрийн хариу бол `ai` tag нэмнэ. Ийм кейсийг `just eval --ai` л уншина.
   - Хэрэв `--ai` ашиглах бол `"profile_name": "<профайлын нэр>"` нэмнэ. Нэргүй бодит кейсийг AI руу хэзээ ч илгээхгүй.

### `answers.csv` баганууд

| Багана | Заавал | Юу бичих |
|---|---|---|
| `date` | ✓ | Дээж авсан (эсвэл хариунд хэвлэсэн) өдөр, `2025-05-03` |
| `name` | ✓ | Шинжилгээний нэр — **хариунд хэвлэснээр нь** (`Креатинин`, `АЛТ`, `Creatinine`) |
| `value` | ✓ | Утга — хэвлэснээр нь: `88`, `5,4`, `<500`, `1.2E+06`, `Сөрөг` |
| `unit` | | Нэгж, хэвлэснээр нь: `мкмоль/л`, `mg/dL` |
| `ref_low`, `ref_high` | | Лавлах хязгаарын доод/дээд тоо: `3.5` ба `5.1`; «< 5» бол зөвхөн `ref_high` = 5 |
| `ref_text` | | Хязгаар тоо биш, эсвэл хүйсээр хэд хэд бол бүтнээр нь: `Сөрөг`, `Эр: 62-115 / Эм: 44-97` (тэр үед `ref_low`/`ref_high` хоосон) |
| `critical_low`, `critical_high` | | Хариунд **критик хязгаар хэвлэгдсэн бол** л |
| `qualitative` | | Утга нь үг бол: `Эерэг`, `Сөрөг`, `Эргэлзээтэй` |
| `test_code` | | Каталогийн код (`CREA`, `K`, `TAC`, `ALT`, … — `seed/lab_tests.json`); мэдэхгүй бол хоосон үлдээвэл «каталогт байхгүй» гэж тооцно |

Хариунд хэвлээгүй зүйлийг бүү нөх: хязгаар байхгүй бол хоосон үлдээнэ. Систем хязгаар зохиовол алдаа гэж тоологдоно.

## Ажиллуулах

```
just eval            # тайлан
just eval --details  # буруу мөр бүрийг дэлгэцэнд (тайланд биш)
just eval --check    # DoD-оос доош бол алдаа
just eval --ai       # танихгүй хэлбэрийг AI-аар (төлбөртэй; ANTHROPIC_API_KEY, EXTRACTION_MODEL)
```

Тайлангийн «Checked answers» хэсэг л DoD-д тоологдоно. Уншигчийн гаралтаас үүсгэсэн хариу (`"source": "reader_bootstrap"`) «Baseline» хэсэгт тусдаа харагдана.
