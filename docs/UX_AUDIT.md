# UX_AUDIT.md — апп-ын UI/UX аудит (2026.11.26)

**Арга:** Pixel API 36 эмулятор (Android 16), demo_kidney, 20+ дэлгэцийн зураг (энгийн, фонт 130%,
харанхуй горим) + ui-reviewer-ийн кодын түүвэр шалгалт (`mobile/src`). Хэрэглэгч — шилжүүлэн
суулгуулсан, ихэвчлэн ахимаг насны, хараа муудсан, стресстэй хүн; апп өдөр бүр 2+ удаа нээгдэнэ.
**Анхаар:** demo_kidney-д бодит утасны туршилтаас үлдсэн 30+ «Туршилтын эм» байгаа тул жагсаалтууд
бодитоос урт харагдсан — тэр хэсгийг тусад нь тэмдэглэв.

## Сайн хийгдсэн
- Монгол текст ойлгомжтой, оношлох/зөвлөх үг алга; тэмдэг = өнгө + дүрс + текст (↑ Лавлахаас их).
- Хүрэлтийн бүс ≥ 48dp (`minTouchTarget`), tab-ын шошго Dynamic Type-д томордог, харанхуй горим ажилладаг.
- «Хариу оруулах» дэлгэц маш тодорхой: хэний профайлд, 3 арга, «галерейд хадгалахгүй» гэсэн итгэл төрүүлэх өгүүлбэр.
- Хандлагын график: тунгийн шат баруун тэнхлэгт, лавлах хязгаар, тэмдгийн дүрс — эмнэлзүйн хувьд баялаг.
- Тун тэмдэглэхэд «Буцаах», офлайн дараалал, Q24 «шалгаж байна».

## Бага
- Урт жагсаалт `ScrollView + map` (results, vitals, events, өнгөрсөн эм) → `FlatList`/`FlashList`.
- `nav-row` дүрс 36×36 тогтмол (фонт 200%-д жижиг); header гарчиг 1 мөр — урт нэрс тасарна.
- Хадгалсны дараа screen reader-т мэдэгдэх (`announceForAccessibility`); onboarding-д «2/3» алхам.
- Тоон оролтод «12,4» таслалыг бүх талбарт хүлээн авах (decimal-pad зарим Android-д зөвхөн «.»).
- Demo өгөгдөл: туршилтын скрипт эм бүрийг шинээр үүсгэдэг — `test_reminder.py` нэг «Туршилтын эм»-ийг дахин ашиглах/цэвэрлэх.
