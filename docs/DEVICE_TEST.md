# DEVICE_TEST.md — бодит утасны шалгалт (BETA B6, 09 «Release бүрийн шалгалт»)

Эмулятор Doze, үйлдвэрлэгчийн батарей хэмнэлт, reboot-ын дараах alarm, бодит камер, бусад апп-аас
share-ийг бодитоор дуурайдаггүй. Утас бүр дээр доорх хүснэгтийг бөглөнө. Утга, нэр, дэлгэцийн зурагт
**зөвхөн демо аккаунт** (`just seed-demo`) — бодит PHI хэзээ ч биш.

## Бэлтгэл
- Утас: Developer options → USB debugging; USB горим File transfer; «Allow USB debugging» → Allow.
- Dev build (`mobile/android`: `gradlew app:assembleDebug -PreactNativeArchitectures=arm64-v8a`) →
  `adb install -r app/build/outputs/apk/debug/app-debug.apk`.
- Сервертэй холбох: `adb reverse tcp:8081 tcp:8081` ба `tcp:8080` (USB-ээр — LAN/Caddy тохиргоо хэрэггүй);
  Metro — `.claude/launch.json` `metro-emulator` (API `http://localhost:8080`, дэлгэцийн зураг зөвшөөрнө).
- Бүртгэх: үйлдвэрлэгч/загвар, Android хувилбар, үйлдвэрлэгчийн батарей горим (Samsung «Sleeping apps»,
  Xiaomi «Battery saver/Autostart»).

## Сануулга (H6, H18, H26 — хамгийн чухал)
Сануулгыг 2–5 минутын дараа болохоор тохируулж шалгана. «Хүлцэл» — ирсэн цаг ба тохируулсан цагийн зөрүү.

| # | Нөхцөл | Хэрхэн | Хүлээлт |

## Олдвор (2026.11.19, POCO X3 NFC)
1. **R4 ❌ — MIUI «Background autostart» анхдагчаар унтраалттай** (энэ утсанд 207 апп-аас 5 нь л асаалттай): `BOOT_COMPLETED` хаагдаж (`process is not permitted to auto start`), утас дахин асахад апп нээгдэх хүртэл **бүх сануулга алга**. Тохиргоо: Security → Background autostart (`com.miui.securitycenter/com.miui.permcenter.autostart.AutoStartManagementActivity`-аар шууд нээгддэг). Апп-ын текст (`batteryXiaomi`) «Тохиргоо → Апп → … → Autostart» гэсэн нь MIUI 14-д таарахгүй.
2. **Сануулгыг сэргээх синк маш удаан:** процесс бүрийн эхний синк бүх сануулгыг (≈45) нэг нэгээр цуцалж байж дахин товлодог; `cancelScheduledNotificationAsync` нэг бүр 2–22 с (MIUI-ийн broadcast саатал) → 3–10 мин сануулгагүй цонх; force-stop-ийн дараа 07:33-ийн сануулга алдагдсан. Ижил ID-аар дахин товлох нь хуучныг сольдог тул цуцлалт шаардлагагүй.
3. **Шинэ эм серверээс (өөр төхөөрөмж/вэб) нэмэгдэхэд сануулга товлогдохгүй**, апп ар талаас урд гарахад `useMedications` дахин татагдахгүй (нүүрний тунгийн жагсаалт өөр query-гаар шинэчлэгдэж харагдана).
4. **Дуу:** суваг `USAGE_NOTIFICATION`, чичиргээ унтраалттай — чимээгүй горимд мэдрэгдэхгүй. Хэрэглэгчийн шийдвэр (2026.11.19): сэрүүлэг шиг дуу (alarm audio, чичиргээ; Тохиргоонд энгийн мэдэгдэл рүү солих), тэмдэглээгүй бол 15 минутын дараа нэг удаа дахин.
5. MIUI ар талын хүргэлт 25–60 с хоцорно (R2, R3) — 30 минутын хүлцэлд багтана.
