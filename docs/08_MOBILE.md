## Гол урсгалууд

### Анх нэвтрэх (админ бүртгэсний дараа)
Нэвтрэх картын QR → апп татах → **идэвхжүүлэх QR** (админы дэлгэцээс) уншуулах эсвэл SMS линк → **өөрийн нууц үг** (≥ 10, хүчтэй байдлын заагч) → зөвшөөрлүүд → биометр санал → **шилжүүлэн суулгалтын wizard** → одоо уудаг эмүүд → Нүүр.

### Шилжүүлэн суулгалтын wizard (≤ 3 мин, алгасаж болно)
1. Ямар эрхтэн? (том дүрстэй сонголт: бөөр, элэг, зүрх, уушги, нойр булчирхай, бөөр+нойр, бусад)
2. Хэзээ? (огноо; "зөвхөн он/сар санаж байна" сонголт)
3. Хаана? (улс — Монгол, Солонгос, Энэтхэг, Хятад, Турк … + хот + эмнэлэг; сүүлд оруулсан эмнэлгүүдээс санал)
4. Донор (амьд — хамаатан/хамаатан бус, нас барсан, мэдэхгүй; хамаарал)
5. "Нэмэлт мэдээлэл" (сонголттой, нээгддэг): цусны бүлэг, CMV статус, HLA, индукц эмчилгээ, шилжүүлэн суулгахад хүргэсэн өвчин, диализ, хянагч эмч
6. "Өөр шилжүүлэн суулгалт бий юу?" (дахин шилжүүлэн суулгалт)

### Эм
- Жагсаалт: **Одоо уудаг** / Өмнө нь уусан; ангиллаар (дархлаа дарангуйлагч эхэнд)
- Нэмэх: каталогоос хайх (монгол, англи, худалдааны нэрээр) эсвэл гараар → хэлбэр, хүч ("1 мг") → тун + хуваарь (өдөрт 2 удаа 08:00, 20:00 гэх мэт) → заавар (эмчийн хэлснээр) → эхэлсэн огноо
- **Тун өөрчлөх:** шинэ тун + огноо + шалтгаан (сонголттой) → хуучин тун түүхэнд үлдэнэ
- **Сануулга:** `expo-notifications` локал хуваарь (сервергүй, offline ажиллана); мэдэгдэл дээр "Уусан" / "10 мин дараа" товч; цагийн бүс, өдрийн хэмнэлт
- **Түгжээтэй дэлгэцийн нууцлал:** анхдагчаар "Эм уух цаг боллоо" (эмийн нэргүй); хэрэглэгч нэрийг харуулахаар сонгож болно
- Уусан/алгассан тэмдэглэл → сарын хураангуй ("Энэ сард 96% цагтаа")
- Систем тун санал болгохгүй, эм хоорондын харилцан үйлчлэл шалгахгүй

### Сануулгын найдвартай байдал (hazard H6, H7)
- **iOS 64 локал мэдэгдлийн хязгаар:** хуваарьлах хоног = `min(7, floor(56 / өдрийн_нийт_мэдэгдэл))` (8 слотыг товлол, "10 мин дараа"-д үлдээнэ); жишээ: 5 эм × 2 = 10/өдөр → 5 хоног. Апп нээгдэх бүрт + background fetch-ээр эргэлдүүлнэ; хуваарь дуусахаас 1 өдрийн өмнө апп нээгдээгүй бол сүүлчийн слотод "Апп-аа нээж сануулгаа сэргээнэ үү". Тооцоог цэвэр функц болгож hypothesis тесттэй.
- **Android exact alarm:** Android 14+-д `SCHEDULE_EXACT_ALARM` анхдагчаар **татгалзсан**. `USE_EXACT_ALARM`-ийг **зарлахгүй** (Google Play үүнийг зөвхөн сэрүүлэг/хуанли апп-д зөвшөөрдөг — эмийн сануулга татгалзагдах эрсдэлтэй). Оронд нь `SCHEDULE_EXACT_ALARM` + тайлбартай дэлгэц ("Эмийн сануулга яг цагтаа ирэхийн тулд…") → системийн тохиргоо руу; зөвшөөрөөгүй бол inexact (≤ 10 мин зөрүү) горимд ажиллаж Нүүрэнд шар анхааруулга. Play Console-ийн permission declaration-д зориулалтыг тайлбарлана. Тухайн үеийн Expo SDK-ийн `expo-notifications` баримтаар (context7) шалгана.
- Samsung/Xiaomi/Oppo батерей оновчлолоос чөлөөлөх алхамчилсан заавар (брэнд тус бүр, зурагтай)
- Мэдэгдлийн зөвшөөрөл унтарсан бол Нүүрэнд улаан анхааруулга "Эмийн сануулга ажиллахгүй байна"
- **Цагийн бүс:** `home` горимд Улаанбаатарын цагаар үлдэнэ; төхөөрөмжийн цагийн бүс солигдоход "Сеулын цагаар шилжүүлэх үү? Тунгийн завсрыг эмчтэйгээ ярилцана уу" гэж асууна
- Мэдэгдлийн товч "Уусан" / "10 мин дараа" — апп хаалттай үед ажиллахыг бодит төхөөрөмж дээр шалгах (боломжгүй бол апп нээгдээд шууд тэмдэглэнэ)

### Асран хамгаалагч (opt-in)
Өвчтөн асран хамгаалагчаа хэрэглэгчийн нэрээр урина → асран хамгаалагч зөвшөөрнө → тохиргоо: "тун **30 мин** (анхдагч) хоцорвол мэдэгдэх", "критик утга". Хоцролтыг өвчтөний утас илрүүлж серверт `{patient_id, kind:'dose_overdue'}` (эмийн нэргүй) илгээнэ → асран хамгаалагчид push "Ээж тань эмээ уусан эсэхийг шалгана уу". Өвчтөн хүссэн үедээ унтраана.

### Яаралтай тусламжийн карт
Эрхтэн, шилжүүлэн суулгасан огноо, төв + утас, одоогийн дархлаа дарангуйлагч эмүүд, цусны бүлэг, харшил, яаралтай холбоо барих хүн. Гаргах хэлбэр: апп-д (биометргүй нээх — **анхдагч OFF**, onboarding-д тайлбартай санал болгоно), түрийвчний карт PDF (mn/en), түгжээтэй дэлгэцийн зураг. iPhone-ий Medical ID-д апп бичих боломжгүй тул гараар нэмэх заавар харуулна.

### Амин үзүүлэлт
Хурдан оруулах: даралт (дээд/доод/судас нэг дэлгэцэнд), жин, температур, сахар, SpO2, шээсний хэмжээ. Хэвийн хүрээг систем тогтоохгүй — эмч зорилт тогтоосон бол (`patient_targets`) харуулна.

### Эмийн түвшин ↔ тун (такролимус гэх мэт)
- Хандлагын график дээр шинжилгээний утга + тунгийн шат (2 дахь Y тэнхлэг) хамт
- Такролимусын хариу батлах үед: уусан тэмдэглэл байвал "Дээж авахаас өмнөх сүүлийн тун: 20:05 (≈12 цаг)" мэдээлэл харуулна — эмчид trough-г тайлбарлахад тус; дүгнэлт хийхгүй

### Эмчилгээ, үйл явдал
Биопси, татгалзал, халдвар, хэвтэн эмчлүүлэлт, диализ, плазмаферез, IVIG, мэс засал, вакцин … — огноо, газар, тайлбар, үр дүн, холбогдох баримт (биопсийн хариу, гарах тойм — зураг/PDF хадгална). График дээр босоо шугамаар.

### Цагийн хэлхээс
Он сараар бүлэглэсэн нэг урсгал: 🫀 шилжүүлэн суулгалт · 💊 эм эхэлсэн/зогссон/тун өөрчлөгдсөн · 🩺 үйл явдал · 🧪 шинжилгээний тайлан. Шүүлтүүр, "Эмчид үзүүлэх" PDF-д оруулах.

### Хариу оруулах (гол урсгал)
1. ＋ товч → "Скан хийх" · "Зургийн сангаас" · "Файл (PDF)"
2. Скан: автомат ирмэг олох, олон хуудас, хуудас бүрийг тайрах/дахин авах
3. Профайл сонгох (хэний хариу?) — сүүлд сонгосныг санана
4. Оруулалт **offline дараалалд** (MMKV) → сүлжээтэй үед background-д илгээх, `client_upload_id`-аар давхардлаас сэргийлэх
5. Явц: "Илгээж байна → Уншиж байна → Хянахад бэлэн" (SSE эсвэл polling + push)
6. Бусад апп-аас: Messenger/Viber/Mail дээрх PDF/зураг → Share → **LabTrack** → 3-р алхам

### Хянах (review) — утсан дээр
- Дээд 40%: эх зураг/PDF (pinch zoom, хуудас солих, тухайн мөр рүү автоматаар гүйлгэх — `source_page`)
- Доод 60%: мөр бүр карт — тест, утга, нэгж, **лавлах хязгаар (баримтаас)**, критик хязгаар, flag; засах бол bottom sheet
- Асуудалтай карт эхэнд (шар), критик бол дээр улаан баннер
- Доод тогтмол товч: "Батлах" (асуудалтай мөр шийдэгдээгүй бол идэвхгүй, "3 мөр шалгах шаардлагатай")

### Нүүр
Профайл сонгогч (дээд) · "Анхаарах" карт (критик, хэвийн бус, хянах хүлээгдэж буй) · гол үзүүлэлтийн картууд (сүүлийн утга, flag, лавлах, sparkline) · сүүлийн оруулалтууд.

### Хандлага
Тест хайх → ECharts шугам + цэг бүрийн лавлах хүрээ (step band) · 3с/6с/1ж/бүгд · утсыг хэвтүүлбэл бүтэн дэлгэц · цэг дээр дарвал эх баримт.

## Тохиргоо ба хүртээмж
- Монгол (үндсэн), англи; Dynamic Type / Android font scale-ийг дагах + апп доторх "Том фонт" горим
- Dark mode, өнгө+дүрс+текст flag, VoiceOver/TalkBack label бүх товчинд, хүрэлтийн бүс ≥ 44pt

## Аюулгүй байдал (төхөөрөмж дээр)
- Refresh token → `expo-secure-store` (Keychain/Keystore)
- Кэш (TanStack Query persist) ба upload дараалал → MMKV **шифрлэлттэй**, түлхүүр secure-store-д; гарахад бүгдийг устгана
- Биометр түгжээ; апп switcher дээр дэлгэцийг бүдгэрүүлэх (privacy overlay)
- Скан хийсэн зургийг апп-ын private хавтсанд; илгээсний дараа устгана; галерейд хадгалахгүй
- Push payload-д PHI байхгүй

## Мэдэгдэл
`review_ready` · `critical_pending` ("Шинэ хариунд яаралтай шалгах утга байж болзошгүй") · `share_invite` · `admin_password_reset` (серверээс, push). Эмийн сануулга — **локал** (төхөөрөмж дээр хуваарьлагдана). Payload зөвхөн i18n түлхүүр + ID; дарахад холбогдох дэлгэц нээгдэнэ (deep link).

## Хэмжүүр
Sentry (crash-free ≥ 99.5%), хүйтэн эхлэл ≤ 2.5 сек, PHI-гүй `product_events` (app_open, dose_logged, upload, review_confirmed) — апп орхилтыг эрт илрүүлэх.

## Тест
Jest + RNTL (компонент), **Maestro** (анх нэвтрэх → нууц үг солих → wizard → эм нэмэх → сануулга → амин үзүүлэлт → скан (mock) → review → батлах → график → яаралтай карт). **Сануулгын тест матриц:** iOS сүүлийн 2 хувилбар; Android — Samsung, Xiaomi, хямд загвар; апп хаалттай, нислэгийн горим, цагийн бүс солих, дахин асаах (reboot)., EAS preview build дээр бодит iPhone + хямд Android (Монголд түгээмэл загвар) дээр гараар.
