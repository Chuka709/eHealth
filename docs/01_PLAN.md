# 01 — Хэрэгжүүлэх төлөвлөгөө (v7)

> v7: Ижил төстэй апп, клиникийн судалгаа, хуулийг судалж (`10_RESEARCH.md`) нэмэлт функц, клиникийн аюулгүй байдлын бүртгэл (`09_CLINICAL_SAFETY.md`) нэмэв.

> **LabTrack MN** — эхний ээлжинд **эрхтэн шилжүүлэн суулгуулсан хүмүүст** зориулсан, гар утас үндсэн, хаалттай бүлгийн апп. 7 удаа хянагдсан (`07_CRITIQUE.md`).

## Шийдвэрүүд (v7.1)
Хариуцагч = өөрийн компани · CV% эмч болон өвчтөнд (тайван тайлбартай) · яаралтай карт түгжээгүй нээх анхдагч OFF · асран хамгаалагчийн мэдэгдэл 30 мин · бета: бөөр ба элэг.

## Зорилго
Шилжүүлэн суулгуулсан хүн насан туршдаа дархлаа дарангуйлах эм ууж, тогтмол шинжилгээ өгдөг. Тэдний шинжилгээ олон эмнэлэг (заримдаа гадаад улс)-аас цаас/PDF хэлбэрээр ирж, эмийн тун байнга өөрчлөгддөг. Апп нь:
- шилжүүлэн суулгалтын мэдээлэл (хэзээ, хаана, ямар эрхтэн, донор …),
- байнга уудаг эм, тунгийн түүх, сануулга,
- эмчилгээ, клиникийн үйл явдал (биопси, татгалзал, хэвтэн эмчлүүлэлт …),
- шинжилгээний хариу (скан/PDF → AI → хүний хяналт; лавлах ба критик хязгаар баримтаас)
-ыг нэг цагийн хэлхээс, хандлагын графикт нэгтгэж, эмчдээ үзүүлэхэд хялбар болгоно.
**Оношилгоо, эмчилгээ, тунгийн зөвлөмж өгөхгүй.**

### MVP
Супер админ хэрэглэгч бүртгэх (нэг нэгээр + CSV)/нууц үг шинэчлэх · биометр түгжээ · олон профайл (хүүхэд) · шилжүүлэн суулгалт · эм + тунгийн түүх + локал сануулга (цагийн бүсийн горим) · асран хамгаалагчийн мэдэгдэл · амин үзүүлэлт · харшил · яаралтай тусламжийн карт · үзлэг/шинжилгээний товлол · эмчээс асуух асуулт · эмчилгээ/үйл явдал · скан/зураг/PDF/share-аас оруулах · AI задлалт → review · нэгж хөрвүүлэлт · критик баннер + push · дашбоард, хандлага (тун давхардсан), цагийн хэлхээс · хуваалцах · "Эмчид үзүүлэх" PDF · өгөгдөл экспорт (PDF/JSON/FHIR) · аудит · mn/en · iOS + Android

### MVP-ийн дараа
Бүрэн web апп · эмчийн самбар · eGFR/MELD тооцоолол · FHIR экспорт · клиник/эмнэлгийн байгууллага · эм хоорондын харилцан үйлчлэл (лицензтэй эмийн мэдээллийн сантай) · локал OCR горим

## Үе шатууд (DoD биелээгүй бол дараагийнх руу шилжихгүй)

### Phase 0 — Суурь
Monorepo (`backend/` uv, `mobile/` Expo, `web/` Next.js, `packages/shared/`, `infra/`, `justfile`) · Docker Compose · FastAPI/Expo skeleton · `just gen-client` · CI.
**DoD:** `just up` ажиллана; dev build утсан дээр API-г дуудна; CI ногоон.

### Phase 1 — Auth, супер админ, профайл
1. Alembic: users, sessions, auth_attempts, patients, patient_access, consents, audit_logs, каталогийн хүснэгтүүд + RLS; `just seed` (lab_tests, medications)
2. `/auth`: login, refresh (rotation + reuse detection), logout, change-password (must_change_password урсгал), sessions, delete-account request; brute-force хамгаалалт
3. `/admin/users`: бүртгэх (түр нууц үг), **CSV бөөн бүртгэл** (шилжүүлэн суулгалтын төвийн жагсаалт; урьдчилан харах, алдааг мөрөөр), хайх, идэвхгүй болгох, түгжээ тайлах, нууц үг шинэчлэх (шалтгаан заавал, бүх сесс цуцлах); `just create-admin` + TOTP
4. Web админ самбар (бүртгэх, нэвтрэх карт хэвлэх, хэрэглэгч удирдах)
5. Апп: welcome, login, анх нэвтрэхэд нууц үг солих, зөвшөөрлүүд, биометр, "нууц үгээ мартсан" (админтай холбогдох), профайл, тохиргоо, админы үйлдлийн түүх
6. Тест: RLS, auth (reuse detection, түгжээ, must_change_password хязгаарлалт), админ PHI харж чадахгүйг батлах, Maestro анх нэвтрэх урсгал

**DoD:** Админ бүртгэсэн хэрэглэгч ≤ 2 мин-д апп-д нэвтэрч нууц үгээ солино; админ нууц үг шинэчлэхэд хуучин бүх сесс цуцлагдана; админ токеноор PHI endpoint 403.

### Phase 2 — Шилжүүлэн суулгалт, эм, амин үзүүлэлт, товлол
1. Alembic: transplants, medication_catalog, medications, medication_regimens, medication_intakes, clinical_events, vitals, allergies, appointments, doctor_questions, emergency_contacts, caregiver_alert_settings + RLS + тест
2. API CRUD; тун өөрчлөхөд шинэ regimen (хуучныг засахгүй); `core/timeline.py` ("шилжүүлэн суулгаснаас хойш" тооцоо)
3. Апп: шилжүүлэн суулгалтын wizard + засах; эмийн жагсаалт, нэмэх (каталог хайлт), тун өөрчлөх, түүх; **локал сануулга** (түгжээтэй дэлгэцийн нууцлал, **цагийн бүсийн горим**, мэдэгдлээс нэг товшилтоор "уусан"); уусан/алгассан; үйл явдал нэмэх
4. Амин үзүүлэлт (даралт+судас нэг дэлгэцэнд, жин, температур, сахар, SpO2, шээсний хэмжээ), харшил, яаралтай холбоо барих хүмүүс
5. **Яаралтай тусламжийн карт:** апп-ын эхэнд нэг товшилтоор (түгжээгүй харагдах сонголттой), түрийвчний карт PDF, түгжээтэй дэлгэцийн зураг (эрхтэн, огноо, төв, дархлаа дарангуйлагч, цусны бүлэг, харшил, яаралтай утас)
6. Үзлэг/шинжилгээний товлол + сануулга; эмчээс асуух асуулт
7. **Асран хамгаалагчийн мэдэгдэл** (opt-in): тун N минут хоцорвол push (төхөөрөмж дээр хоцролт илрүүлж серверт PHI-гүй event илгээнэ)
8. Нүүрэнд шилжүүлэн суулгалтын карт, өнөөдрийн эм, дараагийн товлол

**DoD:** Wizard ≤ 3 мин; сануулга нислэгийн горимд, апп хаалттай үед ч цагтаа ирнэ (тест матриц: iOS сүүлийн 2 хувилбар, Samsung, Xiaomi, хямд Android); цагийн бүс солиход зөв ажиллана; тунгийн түүх зөв; `09_CLINICAL_SAFETY.md` H6–H10 хяналт тесттэй; medical-reviewer хянасан.
**→ Энэ үеэс TestFlight / Play Internal-аар 10–20 бета хэрэглэгч — бөөр ба элэг шилжүүлэн суулгуулсан хүмүүс (шинжилгээний AI-гүйгээр ч эм, сануулгаас үнэ цэнэ авна).**

### Phase 3 — Оруулах
Presigned upload, python-magic, давхардал, ClamAV, Celery; апп: scanner, зургийн сан, PDF, **share intent**, профайл сонгох, offline дараалал.
**DoD:** Нислэгийн горимд скан → сүлжээ орохоор давхардалгүй илгээгдэнэ; Messenger-ээс PDF share ажиллана.

### Phase 4 — AI задлалт
`05_EXTRACTION.md`. Eval: 30+ нэрээ нууцалсан бодит хариу — **бөөр ба элэг шилжүүлэн суулгалтын хяналтын** хариунууд: бөөр (такролимус, креатинин, мочевин, электролит, шээсний ерөнхий/уураг, BK PCR, ЦЕШ), элэг (такролимус, АЛТ/АСТ/ГГТ/ШФ, билирубин, альбумин, INR, HBV DNA/HDV RNA, AFP), хоёуланд CMV PCR; Монгол болон гадаадын (Солонгос, Энэтхэг, Хятад, Турк) эмнэлгийнх, ≥ 50/50 хуваарьтай.
**DoD:** тоон утга ≥ 98%, лавлах хязгаар ≥ 95%, тест таних ≥ 95%; 1 хуудас p95 ≤ 30 сек.

### Phase 5 — Нормчлол, Review
`core/units.py`, `flags.py`, `ranges.py`, `matching.py` + hypothesis; апп review дэлгэц, критик баннер, `critical_pending` push; эмийн түвшний хариу батлахад "сүүлийн тун" мэдээлэл; гараар оруулах.
**DoD:** 5 хүнтэй usability — 1 хуудас утсан дээр ≤ 60 сек.

### Phase 6 — Дашбоард, цагийн хэлхээс
Эрхтнээс хамаарах анхдагч картууд, хандлага (step лавлах хүрээ + эмийн тун 2 дахь тэнхлэгт + үйл явдлын шугам + "хойш хоног" тэнхлэг), амин үзүүлэлтийн график, цагийн хэлхээс, тайлангууд, эмийн дэглэмийн сарын хураангуй, тестийн тогтмол тайлбар (эмчээр хянасан), `latest_results` view.
**DoD:** 3000 утга + 5 жилийн эмийн түүхтэй профайл: Нүүр p95 < 1.5 сек (дунд зэргийн Android).

### Phase 7 — Хуваалцах, PDF, web viewer
Хэрэглэгчийн нэрээр (бүртгэлтэй эмч) болон линк/QR-аар (хугацаа, PIN, үзэлтийн тоо) хуваалцах, web дээр зөвхөн унших (тойм, шилжүүлэн суулгалт, эм, хандлага, амин үзүүлэлт, цагийн хэлхээс), "хэн хэзээ үзсэн", эмчийн тэмдэглэл ба patient_targets (doctor үүрэг), **такролимус CV ба зорилтот хүрээнд байсан хувь (эмч болон өвчтөнд, босгогүй)**, эмийн дэглэмийн хураангуй, "Эмчид үзүүлэх" PDF (асуултуудтай; WeasyPrint, Noto Sans кирилл), **өгөгдөл экспорт** (PDF/JSON/FHIR R4).

### Phase 8 — Дэлгүүрт гаргах, бэлтгэл
`08_MOBILE.md`-ийн жагсаалт, `09_CLINICAL_SAFETY.md` release шалгалт, staged rollout (10% → 50% → 100%), админы таних журмын баримт бичиг + сургалт, зөрчлийн мэдэгдлийн журам, AI үйлчилгээ үзүүлэгчтэй өгөгдөл боловсруулах гэрээ, нууцлалын бодлого, хариуцагч байгууллагатай гэрээ, хуулийн хяналт, pentest, ачааллын тест, нөөцлөлт сэргээх сургуулилт.

### Phase 9+ — Өргөтгөл
Бүрэн web апп · эмчийн самбар · eGFR (CKD-EPI 2021), MELD 3.0 · Apple Health / Health Connect-оос амин үзүүлэлт импорт · клиникийн байгууллага · эмийн харилцан үйлчлэл (лицензтэй сан, зохицуулалтын үнэлгээний дараа) · локал OCR · нийгэмлэг/боловсролын контент.
