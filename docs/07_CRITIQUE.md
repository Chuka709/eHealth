# 07 — Шүүмжлэлт хяналт (v1 → v2 → v3)

Төлөвлөгөөг гурван удаа хянаж, сул талыг олж засав.

## v1 (анхны санаа)
"Next.js frontend + FastAPI (Python) backend + Tesseract OCR + regex-ээр утга задлах + Postgres + JWT өөрсдөө."

## Хяналт №1 → v2

| Асуудал | Яагаад муу | Шийдэл (v2) |
|---|---|---|
| Tesseract + regex | Монгол эмнэлгүүдийн формат олон янз, хүснэгт, гар утсаар авсан муруй зураг — regex нь лаборатори бүрт тусдаа дүрэм шаардана, эвдэрхий | Multimodal LLM (Claude) + JSON schema; regex огт хэрэггүй |
| Python + TS хоёр хэл | Нэг хөгжүүлэгчид 2 runtime, 2 type систем, deploy хүндэрнэ | Бүгд TypeScript; LLM хүнд ажлыг хийдэг тул Python-ий давуу тал багасна |
| Өөрсдөө JWT/auth | Эрүүл мэндийн өгөгдөлд auth-ийн алдаа үнэтэй | Supabase Auth + MFA |
| Эрх зөвхөн апп кодонд | Нэг endpoint-д шалгалт мартвал өгөгдөл алдагдана | Postgres RLS (DB түвшний хамгаалалт) + RLS тест |
| AI үр дүнг шууд хадгалах | Буруу утга дашбоардад орж, буруу ойлголт өгнө | Хүний хяналт (review) заавал, `confirmed` л харагдана |
| Нэг хэрэглэгч = нэг өвчтөн | Эцэг эх хүүхдийнхээ, хүүхэд ахмад эцэг эхийнхээ хариуг удирддаг | user ≠ patient; `patient_access` |

| Асуудал | Яагаад муу | Шийдэл (v3) |
|---|---|---|

| Чанарыг хэмжих аргагүй | Prompt өөрчлөхөд сайжирсан/муудсаныг мэдэхгүй | Eval багц + CI gate |
| Redis/Upstash-д PHI орох эрсдэл | Гадаад үйлчилгээ | Зөвхөн rate limit тоолуур; cache-д PHI хориглох дүрэм |
| Нэгэн зэрэг олон файл → AI rate limit | 429, удаан | Trigger.dev concurrency queue, retry/backoff |
| Эмнэлгийн тооцоолол (eGFR, MELD) | Томьёоны жижиг алдаа клиникийн буруу ойлголт | `packages/core` цэвэр функц + нийтлэгдсэн жишээ утгаар unit тест + эмчийн хяналт |
| Super admin бүх өгөгдөл харах | Дотоод эрсдэл, хууль зөрчил | Анхдагчаар хандахгүй, break-glass + аудит |

## Таны дурдаагүй, нэмсэн зүйлс
1. Гэр бүлийн/асран хамгаалагчийн профайл
2. Эмчтэй хугацаатай хуваалцах, QR линк, цуцлах
3. Шилжүүлэн суулгалтын модуль: дархлаа дарангуйлагчийн зорилтот хүрээ, eGFR, MELD 3.0, үйл явдлын тэмдэглэгээ график дээр
4. Вирусын маркерууд (HBV/HCV/HDV — Монголд тархалт өндөр), CMV/BK вирус (шилжүүлэн суулгалтын дараа)
5. Гараар оруулах, амин үзүүлэлт (даралт, жин)
6. Critical утгын мэдэгдэл, дараагийн шинжилгээний сануулга
7. Аудит лог, зөвшөөрлийн бүртгэл, өгөгдөл устгах эрх
8. "Эмчид үзүүлэх" PDF хураангуй
9. PWA → Expo апп, offline
10. FHIR экспорт (ирээдүйн интеграци), каталогт LOINC код
11. AI зардлын хяналт, квот, давхардал
12. Eval багц, RLS тест, CI gate
13. Хүртээмж (WCAG), ахмад настны том фонт горим

### Эмчийн үүднээс нэмсэн нарийн зүйлс
- **Тун ↔ түвшин:** такролимусын хариуг эмийн тунтай нэг график дээр; дээж авахаас өмнөх сүүлийн тунгийн цаг (уусан тэмдэглэлээс) — trough-г зөв тайлбарлахад эмчид тус.
- **Эрхтнээс хамаарах гол үзүүлэлт:** бөөр (креатинин, BK вирус, шээсний уураг), элэг (элэгний фермент, INR, HBV/HDV — Монголд онцгой), зүрх/уушги (CMV).
- **"Шилжүүлэн суулгаснаас хойш хоног"** тэнхлэг — эмч нар ингэж боддог (эрт үе, эхний жил гэх мэт).
- **Огнооны нарийвчлал:** олон жилийн өмнө, гадаадад шилжүүлэн суулгуулсан хүмүүс зөвхөн он/сараа санадаг.
- **Дахин шилжүүлэн суулгалт**, функцээ алдсан эрхтэн — `transplant_number`, `graft_status`.
- Эмийн каталог нь тун/заалт агуулахгүй — хэрэглэгч эмчийнхээ зааврыг бичнэ.

Такролимус CV% ба зорилтот хүрээнд байсан хувь (v7.1 шийдвэрээр эмч болон өвчтөнд — E2-г үз), гадаадад цагийн бүсийн горим, яаралтай тусламжийн карт, харшил, Android/iOS сануулгын найдвартай байдал.

### D. Хэвээр үлдээсэн, гэхдээ дахин шалгасан шийдвэрүүд
- Python + TS, Expo, FastAPI auth, Celery — хэрэглэгчийн тоо (≤ 2 000) болон багийн хэмжээнд тохиромжтой; хэтрүүлсэн инфра байхгүй.
- Лавлах/критик хязгаар зөвхөн баримтаас — өрсөлдөгчдөөс ялгарах давуу тал.
- Админ бүртгэл — хаалттай бүлэгт тохирно; social engineering хяналт (H12).
