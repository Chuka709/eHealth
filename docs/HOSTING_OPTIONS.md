## Санал
**A — Монголын ISO 27001-тэй үйлчилгээ үзүүлэгчийн VPS** (хаалттай бүлэг, PHI, хуулийн эрсдэлгүй,
код өөрчлөхгүй; анхны төлөвлөгөө ч ийм). Хамгийн багадаа: апп VM (4 vCPU, 8 GB, 100 GB SSD) +
OpenBao-д тусдаа жижиг VM + өөр байршилд шифрлэлттэй нөөц. Шийдвэрийн өмнө 2–3 үйлчилгээ
үзүүлэгчээс: гэрчилгээ (ISO 27001 хамрах хүрээ, Tier), SLA, нөөцлөлт/snapshot, DDoS хамгаалалт,
IPv4, сарын үнэ. Шийдвэр — компани (өгөгдлийн хариуцагч).

## Өөрийн сервер (хэрэглэгчийн сонголт, 2026.11.25)
Хэмжүүрийн суурь: dev stack-ийн сул үеийн санах ой (`docker stats`) — api 145 MB, worker 115,
maint 205, push 85, ai-worker 150, web 55, SeaweedFS 120, Postgres 50 (ачаалалд shared_buffers-ээр
өснө), Valkey 10, Caddy 15 MB; ClamAV ~1.5 GB (гарын үсгийн сан, шинэчлэхэд түр ~2 дахин).
Ачааллын тест: 50 хэрэглэгч 20 хүсэлт/с, p95 96 мс (`LOAD_TEST.md`). Өгөгдлийн өсөлт: PDF/скан
~2 баримт/хэрэглэгч/сар × ~1–3 MB → 500 хэрэглэгчид жилд ~20–40 GB.

| | Бета (≤ 50 хэрэглэгч) | Production (≤ 500, AI унших асаалттай) |
|---|---|---|
| CPU | 4 core (x86-64, AVX2 — OpenCV/pdfium) | 8 core |
| RAM | 8 GB | 16 GB (**ECC**) |
| Диск | 200 GB NVMe SSD | 2 × 500 GB NVMe, **RAID 1**; LUKS бүрэн дискний шифрлэлт |
| Нөөцийн диск/хост | ≥ 500 GB, өөр машин эсвэл өөр байршил | ≥ 2 TB, **өөр байршилд** (Монголд), шифрлэлттэй (`just backup`) |
| KEK (OpenBao) | Ижил серверт тусдаа VM | **Тусдаа** жижиг машин/VM: 2 core, 2 GB, 20 GB |
| Сүлжээ | Тогтмол IPv4, ≥ 50 Мбит/с, зөвхөн 80/443 нээлттэй (SSH — VPN/whitelist) | ≥ 100 Мбит/с; боломжтой бол 2 провайдер |
| Цахилгаан | UPS ≥ 15 мин | UPS + генератортой байр |
| OS | Ubuntu Server 24.04 LTS, Docker Engine + Compose, unattended-upgrades | ижил |

**Шаардлага (PHI тул заавал):**
- Биет аюулгүй байдал: түгжээтэй өрөө/шүүгээ, нэвтрэлтийн бүртгэл; оффисын ширээн дээр биш. Хамгийн
  тохиромжтой нь **өөрийн серверийг Монголын дата төвд колокейшн** (цахилгаан, хөргөлт, сүлжээ,
  биет хамгаалалт) — сервер компанийн өмч хэвээр.
- Диск: LUKS шифрлэлт (сервер хулгайлагдвал өгөгдөл уншигдахгүй); талбарын шифрлэлт (KEK) ч хэвээр.
- Нөөц: өдөр бүр шифрлэлттэй dump + баримт (RPO 24 цаг бетад); production-д WAL архив (PITR,
  RPO ≤ 15 мин); сард нэг `just restore-drill`.
- Мониторинг: диск/RAID-ийн төлөв, санах ой, сертификатын хугацаа, `/healthz`, нөөц амжилттай
  эсэх — алдаа гарвал утсанд мэдэгдэх.
- Домэйн + DNS (`A` бичлэг), Caddy автоматаар TLS (Let's Encrypt — 80/443 гаднаас хүрэх ёстой).
- Хэвийн бус унтралт: апп-ын сануулга утсан дээр ажиллана (сервергүй ч дуугарна); сервер унтарвал
  зөвхөн синк, хуваалцах, шинжилгээ оруулах зогсоно.
