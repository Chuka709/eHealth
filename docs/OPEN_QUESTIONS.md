## Phase 0–1
- [!] **Q1. iOS хөгжүүлэлт (Windows машин).** Xcode, iOS симулятор, Maestro iOS Windows дээр ажиллахгүй. Санал: Android эмулятороор өдөр тутам хөгжүүлж, iOS-ийг EAS cloud dev build + бодит iPhone-оор турших. Phase 0 DoD-ийн "iOS симулятор"-ыг "бодит iPhone" гэж солих. Apple Developer аккаунт ($99/жил) хэрэгтэй. Mac авах эсвэл macOS CI ашиглах эсэх?
- [!] **Q2. `justfile` Windows дээр:** (а) PowerShell-ээр native ажиллах (санал — Docker Desktop, Expo, Android эмулятор Windows-д шууд ажиллана) эсвэл (б) бүх backend-ийг WSL2 дотор.
- [!] **Q3. GitHub репо (CI):** private репо үүсгэх эсэх, нэр. Push-ийг та өөрөө хийнэ (Claude-д хориотой).
- [!] **Q4. Админы хүн таних шалгалт (04 §1):** админ "төрсөн он / шилжүүлэн суулгасан он тохирч байна уу" гэж шалгахад PHI-д хүрнэ. Санал: `security definer` функц зөвхөн `true/false` буцаана, утга хэзээ ч гарахгүй, оролдлого бүр аудитад, хэрэглэгч тус бүр өдөрт 5 удаа хүртэл. Phase 1-д төрсөн он л (шилжүүлэн суулгалтын хүснэгт Phase 2-т).
- [!] **Q5. Шифрлэлтийн түлхүүр** (`national_id_enc`, `totp_secret_enc`, JWT ES256 private key): dev — `.env` / Docker secrets; production — ямар KMS/vault? Санал: Phase 1-д envelope encryption-ий интерфейс, түлхүүр Docker secrets-ээс; production-ий шийдвэрийг Phase 8 хүртэл.
- [!] **Q6. `users.contact_phone`:** хувийн мэдээлэл — шифрлэх үү? Санал: шифрлэж, админд зөвхөн сүүлийн 4 орон + "залгах" үйлдэл аудиттай.
- [!] **Q7. CSV бөөн бүртгэлийн түр нууц үг:** нэг удаа дэлгэцэд + хэвлэх нэвтрэх картын PDF (хэрэглэгч тус бүр нэг хуудас), дахин харах боломжгүй. Зөв үү?
- [!] **Q8. Push (`admin_password_reset`) Phase 1-д:** Expo push credential (FCM, APNs) шаардана. Санал: Phase 1-д апп нээгдэхэд in-app мэдэгдэл, push-ийг Phase 2 (бета-гаас өмнө).
